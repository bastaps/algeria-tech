Algeria Tech

Politique de confidentialité

Dernière mise à jour : 17 octobre 2026

Algeria Tech est un média en ligne d'actualité numérique en Algérie. Ce site se lit sans créer de compte et sans fournir de données personnelles.

Mesure d'audience

Nous comptons les visites avec Cloudflare Web Analytics, un outil conçu pour respecter la vie privée : il n'utilise aucun cookie, ne crée aucun profil et ne suit pas les visiteurs individuellement. Nous obtenons uniquement des statistiques agrégées (pages vues, pays, type d'appareil, performances de chargement).

Données stockées dans votre navigateur

Pour fonctionner plus vite et mémoriser vos préférences, le site utilise le stockage local de votre navigateur (localStorage) : thème d'affichage, cache des derniers articles et compteurs de lecture locaux. Ces informations restent sur votre appareil ; vous pouvez les effacer à tout moment depuis les réglages de votre navigateur.

Services tiers

Certaines fonctions font appel à des services extérieurs. Comme pour toute requête sur Internet, votre adresse IP est alors visible par ces services :

  • Polices : Google Fonts.
  • Vidéos : YouTube (mode « nocookie ») lorsque vous lisez une vidéo intégrée.
  • Météo et taux de change : Open-Meteo et ExchangeRate-API.
  • Traduction : Google Translate, uniquement si vous activez la traduction d'une page.
  • Images d'illustration : certaines images d'articles sont hébergées par leurs sources d'origine.

Hébergement

Le site est hébergé par Cloudflare (Cloudflare Pages) et son code est conservé sur GitHub.

Vos droits

Vous pouvez demander l'accès, la rectification ou la suppression de toute donnée vous concernant, conformément à la loi algérienne n° 18-07 relative à la protection des personnes physiques dans le traitement des données à caractère personnel. Pour toute question, contactez la rédaction via le bouton WhatsApp du site.
