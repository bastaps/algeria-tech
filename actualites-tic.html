Configuration requise — Sources Facebook

Option A · Recommandée · Gratuite

RSS.app (5 feeds gratuits)

1. Créez un compte sur rss.app
2. Collez l'URL de la page Facebook
3. Copiez l'URL RSS → social_config.json → rss_url

Option B · Facebook Developer

Graph API (App Token)

1. developers.facebook.com
2. Créez une App → Graph API Explorer
3. Ajoutez FB_APP_TOKEN=... dans .env

Lancer le script

PowerShell

cd E:\algeria-tech
python fetch_social.py
Automatisation : setup_scheduler.ps1

Pages Facebook exactes
