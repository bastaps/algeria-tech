Alger, 13 septembre 2026 (Algeria Tech) — La nouvelle caméra thermique de poche Rision Magic permet de transformer un smartphone en outil de diagnostic technique. Cet accessoire externe se branche directement sur les terminaux mobiles pour détecter les variations de température.

## Un outil de diagnostic thermique portable pour terminaux mobiles


<figure class="at-photo at-photo--right" style="--w:55%" data-ph="ph_qcpfsf"><img src="/images/inline-1789330621714-vmql2p.webp" alt="" loading="lazy"></figure>


L'appareil Rision Magic se connecte via un port USB-C aux systèmes d'exploitation iOS, Android et Windows. Son utilisation requiert uniquement l'installation d'une application dédiée, sans obligation de créer un compte utilisateur. Ce format d'accessoire externe évite d'avoir à recharger une batterie supplémentaire, l'alimentation étant assurée directement par le téléphone hôte.

Ce dispositif détecte les surchauffes de câblages, les défaillances de batteries ou les défauts d'isolation. Il permet également de localiser des éléments invisibles derrière les cloisons, tels que les tuyauteries, grâce aux écarts thermiques. L'application propose différents modes d'affichage, dont un mode hybride combiné baptisé « AI BiSpectrix ».

Sur le plan technique, l'appareil intègre un capteur natif de 160 x 120 pixels. La technologie QuadIR permet d'élever cette résolution à 320 x 240 pixels pour optimiser la précision des diagnostics. L'affichage bénéficie d'un taux de rafraîchissement de 25 Hz pour assurer la fluidité des vidéos.

| Caractéristique | Spécification technique |
|---|---|
| Compatibilité | iOS, Android, Windows |
| Connectique | USB-C |
| Résolution native | 160 x 120 pixels |
| Résolution optimisée (QuadIR) | 320 x 240 pixels |
| Fréquence de rafraîchissement | 25 Hz |
| Modes d'affichage | Thermique, visible, hybride (AI BiSpectrix) |
| Fonctionnalités de l'application | Suivi des températures extrêmes, réglage de l'émissivité, graphiques de suivi |

* Aucune création de compte ni inscription requise pour utiliser l'application dédiée.
* Résolution d'image optimisée à 320 x 240 pixels grâce à la technologie QuadIR.
* Fréquence de rafraîchissement de 25 Hz garantissant des vidéos fluides sans décalage.
* Alimentation directe par le smartphone hôte éliminant le besoin de recharge externe.
* Fonctionnalités applicatives incluant le suivi des températures extrêmes et le réglage de l'émissivité.
