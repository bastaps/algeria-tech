## Un serveur intégré pour le contrôle par l'intelligence artificielle

La version 11.0.9.565 de l'application NVIDIA, publiée le 13 octobre 2026 et marquée comme bêta, intègre un serveur MCP (Model Context Protocol). Ce standard permet à un assistant d'intelligence artificielle d'utiliser les fonctions d'un autre logiciel. L'option permettant ce contrôle est activée par défaut après l'installation de cette mise à jour sur les PC équipés de cartes graphiques GeForce.

Ce système autorise les assistants compatibles, tels qu'Hermes, OpenClaw ou Perplexity, à interagir avec le logiciel en langage naturel pour exécuter plusieurs actions spécifiques.

| Fonctionnalité | Action de l'agent IA |
|---|---|
| Jeux | Repérer et lancer les titres installés |
| Graphismes | Appliquer les réglages recommandés |
| Capture | Lancer ShadowPlay ou faire des captures d'écran |
| Système | Lire les informations du pilote et modifier les réglages d'alimentation |

## Procédure pour désactiver l'accès des agents

Le serveur fonctionne en permanence en arrière-plan dès l'allumage et écoute uniquement à l'adresse locale 127.0.0.1 sur le port 13508, ce qui signifie qu'aucun service externe n'est branché directement sur la machine sans agent installé. Néanmoins, cette activation par défaut suscite des interrogations en matière de sécurité informatique.

Pour couper l'accès et arrêter le serveur, il suffit d'ouvrir l'application NVIDIA, de se rendre dans les paramètres et de consulter l'onglet des caractéristiques. Dans la section dédiée, l'interrupteur permettant aux agents d'intelligence artificielle de contrôler l'application peut être désactivé manuellement.

## À retenir

- La version 11.0.9.565 de l'application NVIDIA active un serveur MCP par défaut.
- Des assistants comme Hermes, OpenClaw ou Perplexity peuvent piloter le logiciel.
- L'option est désactivable dans les paramètres de l'application.
