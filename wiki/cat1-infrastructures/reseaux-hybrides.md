# Réseaux hybrides

## Définition
Un réseau hybride de télécommunications combine deux technologies de transmission différentes pour optimiser la couverture haut débit à moindre coût. La configuration la plus courante est le **FTTC** (Fiber To The Cabinet) : la fibre optique est déployée jusqu'aux armoires de rue, puis la connexion vers l'abonné s'effectue sur la paire de cuivre existante via VDSL2. Cette approche permet d'atteindre des débits de 50 à 100 Mbit/s sans remplacer intégralement l'infrastructure cuivre, ce qui réduit considérablement les coûts et les délais de déploiement.

## Contexte Algérien
Dans le contexte algérien, les réseaux hybrides constituent une solution de transition pragmatique entre le réseau cuivre vieillissant (ADSL) et le déploiement intégral de la fibre FTTH, dont le coût et le temps de déploiement sont importants. Algérie Télécom a expérimenté des architectures FTTB (Fiber To The Building) dans certains quartiers urbains. Ces solutions permettent d'améliorer rapidement les débits dans les zones denses sans attendre le déploiement complet de la fibre. Le réseau hybride fibre-satellite est également utilisé pour connecter les zones rurales isolées dans le cadre du programme de service universel.
