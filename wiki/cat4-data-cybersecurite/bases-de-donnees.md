# Bases de données

## Définition
Une base de données est un système organisé de stockage et de gestion d'informations structurées, permettant leur consultation, modification et suppression efficaces. Les systèmes de gestion de bases de données (SGBD) relationnelles (MySQL, PostgreSQL, Oracle, SQL Server) utilisent le langage SQL. Les bases de données NoSQL (MongoDB, Redis, Cassandra) sont adaptées aux données non structurées et aux très grands volumes. Les bases de données sont au cœur de toutes les applications modernes.

## Contexte Algérien
Les bases de données sont utilisées dans tous les secteurs en Algérie : l'administration (fichiers d'état civil, registres fiscaux, bases de sécurité sociale), les banques (comptes clients, transactions), les opérateurs télécoms (abonnés, facturation) et les entreprises privées. La sécurisation des bases de données est un enjeu critique : des incidents de fuite de données de bases algériennes ont été signalés sur des forums spécialisés. Les développeurs algériens utilisent principalement MySQL et PostgreSQL pour leurs projets. Oracle est présent dans les grandes entreprises et administrations. La transition vers des bases de données cloud (AWS RDS, Azure SQL) commence à s'opérer dans les entreprises innovantes.
