# Cloud souverain

## Définition
Un cloud souverain est une infrastructure cloud hébergée sur le territoire national, soumise au droit local et opérée par des entités nationales ou sous contrôle national. Il garantit que les données stockées restent sous la juridiction de l'État, protégées des accès étrangers (notamment des lois extraterritoriales comme le Cloud Act américain). Le cloud souverain peut être public (géré par l'État), privé (par une entreprise nationale) ou hybride.

## Contexte Algérien
Le projet de **cloud gouvernemental algérien** est un axe majeur de la stratégie numérique nationale. L'objectif est de disposer d'une infrastructure cloud nationale pour héberger les données et applications des ministères, agences et établissements publics, réduisant la dépendance à des hyperscalers étrangers. Algérie Télécom est le principal prestataire envisagé pour ce cloud gouvernemental, s'appuyant sur ses data centers existants. Des investissements sont prévus pour renforcer les capacités (puissance de calcul, stockage, résilience). Des entreprises locales comme Stream System et des partenaires technologiques (Huawei, Dell) participent à ce projet. La définition d'un cadre technique et réglementaire du cloud souverain algérien est en cours.
