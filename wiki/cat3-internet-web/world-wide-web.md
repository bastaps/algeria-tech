# World Wide Web (WWW)

## Définition
Le World Wide Web (WWW) est un système d'information hypertexte distribué, fonctionnant sur Internet, qui permet d'accéder à des pages web reliées entre elles par des liens hypertextes. Inventé par Tim Berners-Lee en 1989, le Web utilise le protocole HTTP/HTTPS, le langage HTML et le système d'adressage URL. Il est la face la plus visible d'Internet mais ne constitue qu'une partie de celui-ci (l'email, les applications mobiles, etc. utilisent aussi Internet sans passer par le Web traditionnel).

## Contexte Algérien
La présence web algérienne s'est considérablement développée depuis les années 2010. Des milliers de sites web en arabe, français et berbère existent aujourd'hui, couvrant l'actualité (TSA, El Watan, Liberté), le commerce électronique, l'éducation et les services gouvernementaux. Le domaine national **.dz** est géré par le CERIST (Centre de Recherche sur l'Information Scientifique et Technique). Des plateformes algériennes locales (Yassir, Ouedkniss, Jumia Algérie) ont émergé comme alternatives aux plateformes internationales. La création de contenus web en langue arabe algérienne et en tamazight reste un enjeu de représentation numérique.
